# 🏦 Loan Risk Prediction using K-Nearest Neighbors (KNN)

An end-to-end Machine Learning project developed as part of a Data Mining course to automate and optimize credit risk assessment in the financial sector. 

The pipeline handles data exploration, visualization, preprocessing, and classification to predict whether a loan application should be approved or rejected — reducing financial default risk and accelerating decision-making.

---

## 📌 Project Overview

| Metric / Aspect | Details |
| :--- | :--- |
| **Problem** | Manual loan assessment is slow, error-prone, and inconsistent, leading to financial risk. |
| **Solution** | Machine Learning model (KNN) trained on applicant financial profiles to automate approval. |
| **Primary Metric** | **90% Accuracy** achieved on the test dataset. |
| **Role & Contribution** | Personally responsible for EDA (Exploratory Data Analysis) and KNN model development. |

---

## 🛠️ Tech Stack & Libraries
- **Language**: Python
- **Environment**: Jupyter Notebook
- **Libraries**:
  - `pandas` & `numpy` — Data manipulation & cleaning
  - `matplotlib` & `seaborn` — Exploratory data analysis & visualization
  - `scikit-learn` — Model building, KNN implementation & evaluation metrics

---

## 🔬 Workflow Pipeline
1. **Data Ingestion & Cleaning**: Handling missing values, encoding categorical variables, and feature scaling.
2. **Exploratory Data Analysis (EDA)**: Visualizing feature correlations, income distributions, and credit history impact.
3. **Model Training**: Implementing the K-Nearest Neighbors (KNN) classification algorithm.
4. **Evaluation**: Assessing performance via accuracy score, confusion matrix, and classification report.
